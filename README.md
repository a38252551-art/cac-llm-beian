# 生成式 AI 服务备案 / 登记检索工具

把国家网信办分散在各月份 PDF 附件里的「生成式人工智能服务备案 / 登记」名单，整合成**一个可搜索、可核验原文**的本地网页。数据只来自网信办公布的原始 PDF，不做任何人工改写。

## 一、怎么用（零基础）

- **只想查询**：进入 `site` 文件夹，双击 `index.html`，用浏览器打开即可（无需联网、无需安装、无需登录）。
- **想更新到最新名单**：双击项目根目录的 `run.bat`。它会自动：① 抓取网信办最新公告与 PDF → ② 重新解析、校验 → ③ 打开检索页。
  - 原理：`run.bat` 依次运行 `fetch.py`（采集）和 `parse_build.py`（解析建站），并已设置好中文编码，无需你手动配置。

## 二、怎么搜

在顶部搜索框输入后点「搜索」或按回车。支持：

| 想找 | 输入示例 |
| --- | --- |
| 公司 / 产品全称 | `北京百度网讯科技有限公司`、`文心一言` |
| 公司 / 产品简称 | `百度`、`字节`、`荣耀` |
| 拼音 | `doubao`、`douyin`、`xuanji` |
| 拼音首字母 | `bd`（百度）、`wx`（文心）；多个词用空格，如 `bd wx` |
| 备案号 / 登记号（或片段） | `20260706S0055`、`WenXinYiYan` |

- 多个词用空格分隔，表示「同时满足」。
- 结果按相关度排序：编号精确命中 > 编号包含 > 简称/拼音命中 > 一般包含。
- 可配合「类别」「属地」「应用领域」筛选与排序，所有条件同时生效。
- 在「查找应用领域」输入名称，再从「应用领域」下拉框选择；也可直接点击法律、教育、医疗、金融、通用等常用领域。括号中显示对应记录数，多领域记录会分别计数。
- 「清空筛选」恢复全部记录；业务不明确的产品可以选择「未标注」查找。
- 搜不到时，页面会基于编辑距离给出「你是不是想找」的提示。

## 三、怎么核验是官方原文（不被篡改）

每条结果下方都有：

- **官方公告**：打开网信办对应的公告页面；
- **PDF 第 N 页**：打开本地归档的原始 PDF 并跳到对应页，可逐字对照；
- **SHA + 短串**：该 PDF 的 SHA256 指纹前缀。若文件被改动，指纹会变化（完整指纹见 `sources/manifest.json`）。

## 四、想新增「简称 / 别名」

编辑根目录的 `aliases.csv`，每行三列：`别名,目标,备注`，保存后重新双击 `run.bat`（或只运行 `parse_build.py`）即可。

- 「目标」可写**编号**（精确到某一条），或写**名称/单位里的关键字**（对所有包含该关键字的记录生效）。
- 示例：`字节,抖音,` —— 因为字节跳动相关备案的登记主体是「北京抖音信息服务有限公司」。

## 五、数据范围与口径

- 仅覆盖**生成式人工智能服务备案、手机端侧备案、应用登记**三类；不含「算法备案 / 深度合成」（那是另一套系统 beian.cac.gov.cn）。
- 当前解析结果：服务备案 1105 条、手机端侧备案 10 条、应用登记 731 条，合计 1846 条；三类序号均无缺口（详见 `qa_report.md`）。
- 个别 PDF 中编号被相邻行遮挡的情况，会在 `qa_report.md` 的「编号不完整」列出，并在 `manual_records.json` 中按编号规则补全（备注里写明依据）。

## 六、应用领域分类

分类名称参考竞品网站的可见应用领域选项，保留教育、医疗、金融、政务、工业、文娱、交通、能源、科研、通用等分类，并提供法律等细分领域。

这些标签是辅助检索信息，不是网信办原始字段，也不保证每条产品的标签与竞品一致。按产品名称中的明确关键词分类，业务不明确的记录保留「未标注」。每条结果可以展开「分类依据」查看依据。

`application_domain_rules.json` 保存分类词表、关键词规则和按编号配置的人工分类；编号键使用小写。调整后运行 `parse_build.py` 即可重建，之后的数据更新也会继续应用这些规则。`application_domains.py` 处理辅助标签，`site_template.html` 是网页源模板。

## 七、目录说明

```
大模型备案检索/
├─ run.bat              一键更新并打开
├─ fetch.py             采集器（抓取公告、下载 PDF/图片、写 manifest）
├─ parse_build.py       解析 + 校验 + 生成网页
├─ aliases.csv          自定义简称/别名
├─ manual_records.json  图片表格转写 + 被遮挡编号补全
├─ requirements.txt     Python 依赖清单
├─ qa_report.md         数据校验报告
├─ data/records.json    结构化数据（网页即用它内联生成）
├─ site/index.html      检索页（双击打开）
└─ sources/
   ├─ manifest.json     每个来源文件的 URL、SHA256、页码映射
   ├─ pdfs/             网信办原始 PDF（13 个）
   └─ images/           公告中的表格图片
```

> 数据来源与口径以国家网信办原始公告为准。项目可生成本地检索页，以及用于现有 GitHub Pages 站点的 `deploy` 部署目录。
